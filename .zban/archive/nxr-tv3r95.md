## Summary of Changes

`napi-build` is inferred for a `cdylib` crate that depends directly on `napi` (normal dependency, any platform), or by `artifacts` (`src/graph/napi.ts`, `targets.ts`), runs `@convesoft/nx-rust:cargo-outputs`, takes `features`, `allFeatures`, `noDefaultFeatures` and `profile` and the `all-features` configuration, and no `targetTriple`. Outputs are `{projectRoot}/<binaryName>.<platform>-<arch>[-<abi>].node`, `index.js` and `index.d.ts`, named at graph creation from the crate's `package.json` and the host triple of `rustc -vV`, and excluded from the crate's named input `default`. Its key adds a runtime input that prints the version of the `@napi-rs/cli` that Node resolves from the crate's folder (`src/tools/print-napi-cli.ts`) and `npm_new_version`; the host is in the toolchain input. The executor (`src/executors/napi-build.ts`) fails before cargo for a shared library name, a missing `package.json`, a missing, older or other-major CLI, a non-host triple and a graph/CLI name mismatch; asks `cargo tree -e normal` with the compile's selection and flags for the closure; fails a closure with `napi-derive` of another major; empties `<build dir>/nx-rust/napi/<hash>/types`, forces every napi-derive crate of the closure, runs the group through `runGroup` (with the lockfile post-check and the build input check), checks each forced crate's file and post-processes with `readNapiConfig`, `parseTriple`, `generateTypeDef` and `writeJsBinding` as `napi build --platform` 3.10.12 does. A napi compile counts as a `build` group for the files that a batch stores; groups now key on the target, since `build` and `napi-build` run one command. `init` counts the napi CLI as needed per crate with `napi-build`. Knowledge: `DES-NAPI` (decisions, the options marked provisional), `DES-BATCH`, `DES-TARGETS`, `DES-OUTPUTS`, `DES-INPUTS`, `DES-PLUGIN-OPTIONS`, `DES-DIAGNOSTICS` (three rows), the guide in `artifacts.mara.md`, `execution.mara.md`, `targets.mara.md`, `verification.mara.md`. Tests get the CLI as a root dev dependency linked into the fixture copy, and the crates from a Cargo local registry in the fixture `napi-addons`. Backlog: nxr-d5n6zr (the CLI's own dependencies in the key).

Rejected: reading the library path from cargo's JSON messages (a group of one crate runs the plain command, without them); `cargo metadata` for the closure (its feature resolution differs from the compile's); glob outputs for the addon (would store other platforms' files); vendoring unpacked crate sources (18 MB against 2.8 MB of `.crate` files).
