Goal: `nx release publish` publishes the crates of each Cargo workspace with one `cargo publish` call per registry, to the registry that Cargo's settings choose, and its dry run checks the whole set.

Implements the paragraphs Publish target, Batch, Registries, Target registry, Lookups, crates.io replaced, Where a dependency points, the checks _Dependencies published elsewhere_ and _Dependencies published first_ of Checks before each call, Dry run, Existing versions, Tracked files, Credentials and tree, Options and Without a batch of `DES-RELEASE` (`nx-rust/docs/release.mara.md`), with `ADR-BATCHED-PUBLISH`, `ADR-PUBLISH-REGISTRY-OPTION` and `ADR-PUBLISH-REPLACED-CRATES-IO` (`nx-rust/docs/decisions.mara.md`) and the row and sentences of `DES-TARGETS` and `DES-PLUGIN-OPTIONS` that name `nx-release-publish`. Checked by groups 6, 7 and 9 of `VER-RELEASE`. Rests on the batch executor of milestone 0.2 (nxr-s12cpg), on the harness registry (nxr-52c1bx) and on the lockfile step (nxr-n6z9x6), because group 6 starts with a version run that brings `Cargo.lock` up to date.

Until 14 November 2026 this issue bundled the whole release implementation and planned that `targetNames` renames the publish target. ## Summary of Changes

- Checked first, with real Nx 24.0.6 and a stand-in executor with `preferBatch`, that `nx release publish` and `nx release` hand each release group's runnable `nx-release-publish` tasks to one batch, in the order of the reported dependencies, narrowed by `--projects` and `--groups`, and that `NX_BATCH_MODE=false` runs each task alone: `EVD-NX-24-PUBLISH-BATCHES`, with `RISK-NX-RELEASE`, `EVD-NX-24-RELEASE`, `EVD-NX-24-VERSION-ACTIONS` and the "Settled during implementation" list of `DES-RELEASE` updated. The tests later showed that Nx's release filter also selects a selected crate's dependents in another group, which the evidence records.
- `nx-release-publish` on every crate without `publish = false` (uncached, no `dependsOn`), refused as a `targetNames` key with the message of `DES-PLUGIN-OPTIONS`; the executor `@convesoft/nx-rust:release-publish` with a batch implementation and `preferBatch` in `nx-rust/src/release/publish.ts` and `publish-cargo.ts`, implementing Publish target, Batch, Registries, Target registry (default variable or probe in a folder of its own in the system's temporary folder), Lookups, crates.io replaced, Where a dependency points, _Dependencies published elsewhere_, _Dependencies published first_, Dry run, Existing versions, Tracked files, Credentials and tree, Options and Without a batch. `init` adds the empty entry for the executor; `setup.mara.md`, `targets.mara.md` and `VER-SETUP` name five entries.
