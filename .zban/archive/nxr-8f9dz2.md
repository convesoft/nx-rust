## Summary of Changes after the review of 0132d56

Two findings fixed. Stored files (P1): a task whose own options give it a feature set (`features`, `allFeatures` or `noDefaultFeatures` from the crate's table, a `project.json` or `targetDefaults`) is now a group of one crate that selects only its crate, whatever else the batch holds, also where a configuration gives other tasks the same flags (`ownFeatureSet` in `task.ts`, `groupKey` and `groupSelection` in `groups.ts`). Each wave runs its whole-workspace groups first, and a whole-workspace `build` group of a workspace root in which a `build` group of the batch has already run is left unreported, together with its dependents, so that Nx runs it in a following batch process after storing the rest (`wholeWorkspaceFirst` and `writesStoredFiles` in `batch.ts`).
